# Dataset output license policy

The license of the released dataset is derived from the model that generated
the released responses.

| Generator license class | Released dataset license |
| --- | --- |
| Permissive open-source license (Apache-2.0, MIT, BSD) | Apache-2.0 |
| Proprietary hosted model whose terms permit redistribution of outputs | ODC-BY-1.0 |
| Evaluation-only or output-restricted model terms | not releasable |

Choose the row that matches the generator recorded in `docs/dataset_card.md`
and the license inventory in `legal/model_terms.md`.
